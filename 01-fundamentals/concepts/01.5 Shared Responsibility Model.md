# Shared Responsibility Model

basic idea:

` AWS is responsible for security OF the cloud, while customers are responsible for security IN the cloud.`

But the exact customer responsibility depends on the AWS service we're using.

## AWS Responsibility

AWS is responsible for the infrastructure that runs AWS services.

This includes things such as:

- Physical data centers
- Physical servers
- Physical networking
- Hardware
- Facilities
- Underlying infrastructure
- AWS-managed virtualization infrastructure

```
                 AWS Responsibility
                        │
          ┌─────────────┼─────────────┐
          │             │             │
       Physical      Hardware      Infrastructure
     Data Centers
```

we don't need to manage AWS's physical servers.

## Customer Responsibility

we are responsible for things that we configure, deploy, or put into AWS.

Depending on the service, this can include:

- Our application
- Our data
- IAM permissions
- Access control
- Security configuration
- Network configuration
- Operating system
- Encryption configuration
- Application dependencies

## The Responsibility Changes With the Service

PostgreSQL on EC2. We have a lot of responsibility.

```
AWS
│
└── EC2 infrastructure
        │
        └── You
             ├── OS
             ├── PostgreSQL
             ├── Configuration
             └── Application
```

PostgreSQL on RDS

```
AWS
│
└── RDS
     │
     └── PostgreSQL
           │
           ├── Database configuration → we
           ├── Schema                → we
           ├── Data                  → we
           └── Application           → we
```

AWS takes responsibility for more of the underlying infrastructure and managed database operations.

## EC2 vs RDS Example

Imagine your Go application uses PostgreSQL.

Option A — PostgreSQL on EC2

```
                AWS
                 │
                EC2
                 │
       ┌─────────┴─────────┐
       │                   │
      OS              PostgreSQL
       │                   │
       └─────────┬─────────┘
                 │
              Go API
```

we manage a lot.

Option B — RDS PostgreSQL

```
               AWS
                │
        ┌───────┴───────┐
        │               │
       RDS            Go API
        │
   PostgreSQL
```

AWS manages more of the infrastructure.

we still manage your database configuration, data, access controls, and application integration.

`AWS is responsible for the security of the underlying cloud infrastructure, while the customer is responsible for security of their workloads and configurations; the exact division depends on the service.`
